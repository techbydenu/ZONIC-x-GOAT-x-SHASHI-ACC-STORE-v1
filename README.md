# SHASHIxGOATxZONIC ACCOUNT STORE

Free Fire SG Region Trusted Account Store Website - Designed for **Vercel** & GitHub deployment.

## 🚀 How to Add Banner Image:
1. Copy your banner image (the attached poster).
2. Rename it to `banner.jpg`.
3. Paste it directly into this project folder alongside `index.html`.

## 📦 How to Deploy to Vercel:
1. Upload this extracted folder / files to a new GitHub Repository.
2. Go to [Vercel.com](https://vercel.com) and log in.
3. Click **Add New Project** -> Select your GitHub Repo.
4. Click **Deploy**. Your live website link will be ready in 30 seconds!
